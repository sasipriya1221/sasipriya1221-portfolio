# The Trailer

The portfolio of **Sasipriya Kalimuthu**: AI security and machine learning. Seven projects, each told as the threat and the defence she built.

**▶ Live:** [sasipriya-kalimuthu.vercel.app](https://sasipriya-kalimuthu.vercel.app)

## What's inside

| Path | What it is |
|---|---|
| `index.html` | The whole site in one hand-written page: no framework and no build step. GSAP drives the scroll scenes; canvas draws the embers, snow and the intro map. |
| `oasis-live.html` | The Oasis live demo page. |
| `assets/` | Project screenshots and her photo. |
| `vercel.json` | Security headers: `nosniff`, frame denial, referrer and permissions policies. |
| `og-image.jpg` | The link preview shown when the site is shared. |

## Run it locally

Open `index.html` in a browser, or serve the folder with `python -m http.server`.
